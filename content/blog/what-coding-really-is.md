## Who suits coding?

I would say, people that doesn’t give up, lots of patience, love problem solving, like to learn new stuff from google, curious, and love to get everything planned before executing something (yeah all the positivity). It takes time to develop coding skills, just like how long we take to master our languages to be able to communicate with others, or drawing skills. In my humble opinion, **coding is all about logic, and is a tool to implement humans’ idea into the computer.**

## Coding = Programming = Communicate with Computer = Problem solving

Let’s think. We talk to people surrounding us. The people listen (input) and replied you by voicing out through their mouth (output). What’s happening in the middle? Analyzing, building up sentences.

Similarly, when I double click a document in the desktop with a mouse (input), the CPU process it, and open the documents for me (output). In this case, coding is acting as a bridge of communication between me and my computer. **In short, coding is about guiding computer what we humans desired and wanted them to do. But how? Using programming languages.**

We use English, Chinese, Japanese and many more languages to communicates among humans. Similarly, we use C, C#, Python and many more programming languages to communicates with computers, and each of them has their own advantages (faster, easier and etc.).

So, which languages should I start? In my opinion, is **any one of them**. Preferably I will choose C++, Java, or Python to kick off my coding journey. Why? ## All programming languages have the same concepts to master.

In general, the world or computer is all about 0 or 1, ‘a’ or ‘b’. For example, should I continue to read this article, or just quit and find a better one? 
(please read till the end luv u).

All the languages share the same structures, and all the programs now available in the world implemented these concepts. I will list out the most basic blocks here to be mastered for new coder:

1. Math operations (how to 1+1 using programming languages)

2. Types of variables (integer, float, string, Boolean etc.).

3. If-else statements.

4. Loops (For loop, While loop).

5. Receive inputs and giving outputs.

Let me get a very simple example for you.

I just wake up from sleep in the morning. There are two options for me: get ready or continue to sleep. If today is school day, then I probably will get up and get ready. Else, I will continue to sleep. In this scenario, I can code it using ‘if-else’ statements to let the computer act like me:

```
if iamwake():
    if schoolDay == True: 
        getready() 
    else: 
        sleep()
```

If I wish to execute this while I am alive, I can simply add a while loop outside:

```
While True:
    if iamwake():
       if schoolDay == True: 
           getready() 
       else: 
           sleep()    if iamdead():
        break
```

(By the way the language I used here is called Python.)

Once you mastered all the basic concepts underlying a programming language, learning other languages will not be a hassle too (you know I know you know it). **With these concepts, depends on your creativity, you can build any programs based on the basic concepts.**

## What problem solving really means in coding?

One of the world’s problems is about the repetitive jobs. There’s term you can search for to get the idea: ‘RPA — Robot Process Automation’. Just a quick example on what you can really do in RPA:

1. Create a bot to help me reply in my business (Chat Bot)

2. Generate reports based on the daily excel report and email them to the targeted email list. (Daily business reporting)

3. Generating e-certificates with names listed in a file (sorry I am running out of ideas).

Of course, coding can solve way more problems that I can’t possibly list them all. When you understand how to have a basic communication with the computers, coding will become super fun.

To challenge yourself, click [here](https://leetcode.com/), press on contest tab, navigate to any contest (for example Weekly Contest 254), scroll down, and pick any problem from the problem list. And that’s where you can test how well you can communicate with the computer to solve real life problem. These questions meant to be enhancing your skills in data structure, which is about maximizing the program efficiency and minimizing the memory usage.
